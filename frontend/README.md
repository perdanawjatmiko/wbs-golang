# WBS frontend

Next.js App Router, TypeScript strict dan Tailwind CSS. Setup dan commands lengkap: [repository README](../README.md). Keputusan integrasi server-side API: [development](../docs/development.md).

```sh
npm install
cp .env.example .env.local
npm run dev
```

API_BASE_URL hanya tersedia pada server. Jangan menaruh secret dalam NEXT_PUBLIC_*.
